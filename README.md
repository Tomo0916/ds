# データで挑む競馬分析

専門学校データサイエンス学科の授業（毎週水曜日）で使う、生徒向けの教材です。
競馬のデータを使って、複雑なデータを「視点」で切る力を身につけます。資金はすべて仮想で、実際には賭けません。

日本語・やさしい日本語・英語・ネパール語・フランス語・ミャンマー語・ベンガル語・シンハラ語・インドネシア語・ベトナム語・中国語の11言語に対応しています。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | 目次ページ（全11回の日程と教材へのリンク） |
| `lessons/01/index.html` | 第1回の読み物（出馬表の練習・オッズのしくみ・確認クイズ） |
| `lessons/01/slides.html` | 第1回のスライド（← → キーで移動） |
| `lessons/01/i18n/<言語>.json` | 第1回の本文（言語ごと） |
| `i18n/<言語>.json` | サイトのタイトルと各回のタイトル（言語ごと） |
| `assets/` | 共通の部品（言語切り替え、体験ツール、日程、画面の文言） |

授業で使う競馬データは、Kaggle の「JRA日本中央競馬会 Horse Racing Dataset」です。
データは生徒が各自のアカウントでダウンロードし、このリポジトリには含めません。
